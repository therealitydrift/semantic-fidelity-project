# Semantic Fidelity Project

The Semantic Fidelity Project is the primary public GitHub repository for the Semantic Fidelity framework by A. Jacobs.

Semantic Fidelity describes the degree to which a representation preserves the meaning, intent, context, distinctions, and referential relationships necessary for its intended use. The project examines how meaning changes as information moves through retrieval, compression, summarization, translation, generation, memory, optimization, and recursive reuse.

A representation can remain fluent, accurate, and internally coherent while becoming less faithful to what its source meant. The project therefore focuses not only on factual correctness, but on whether meaning, hierarchy, implication, uncertainty, provenance, and reference survive transformation.

> Coherence is not contact. Presence is not preservation.

## Core Framework

Semantic Fidelity is a preservation property. It asks whether a transformed representation still carries the meaning required for its intended use.

The framework treats meaning as relational rather than purely lexical. Preserving words is not enough if the transformation changes emphasis, hierarchy, implication, uncertainty, audience, intent, context, or reference. A summary can be factually correct while being semantically unfaithful. A retrieved passage can be relevant while supporting the wrong interpretation. An AI output can be fluent and plausible while subtly changing what the source was doing.

The project therefore examines what happens across the full transformation chain rather than evaluating only the final output.

A simplified sequence is:

**Source → Representation → Transformation → Optimization → Recursion → Semantic Drift**

The central question is whether the representation remains answerable to the relationships that made the source meaningful.

## Semantic Fidelity in AI Systems

AI systems make Semantic Fidelity especially important because they routinely transform information through several representational layers before producing an output.

A typical workflow may include query interpretation, embeddings, retrieval, ranking, context selection, summarization, generation, memory, tool use, and later reuse. Meaning can change at any of these points without producing an obvious factual error.

The project examines failure modes such as retrieval drift, interpretation failure, context drift, memory drift, agent drift, provenance failure, and evaluation blindness. These failures can produce outputs that look successful according to conventional measures while becoming less faithful to the source, user intent, or real-world conditions they were meant to preserve.

For this reason, the project treats accuracy as necessary but insufficient. Evaluation also needs to ask whether the meaning that mattered survived the workflow.

## Semantic Observability and Evaluation

Semantic observability is the ability to inspect how meaning changes across a representational chain rather than judging only the final output.

A fidelity evaluation asks what needed to survive the transformation. This can include intent, relationships, context, hierarchy, uncertainty, reference, constraints, and downstream function.

The project therefore emphasizes questions such as:

- What did the source originally mean?
- What was selected, omitted, or compressed?
- Which constraints governed interpretation?
- Did the hierarchy of importance change?
- Can the current output still be traced back to its source?
- Did later stages inherit earlier distortions?
- Can contradictory source evidence still force revision?
- Can the system report success while meaning has degraded?

Textual similarity, citation presence, factual accuracy, and relevance can all be useful, but none is equivalent to Semantic Fidelity.

## Relationship to Reality Drift

The Semantic Fidelity Project is part of the broader Reality Drift framework.

Reality Drift describes the systems-level condition in which a system remains operational and internally coherent while progressively losing corrective contact with the reality it was built to represent or act upon. Semantic Fidelity focuses on whether meaning survives the transformations occurring inside those systems.

Semantic Drift can contribute to Reality Drift. Recursive Compression carries earlier losses forward. Proxy substitution gives representations operational authority. Constraint Collapse weakens correction. Provenance failure makes source meaning difficult to reconstruct. Evaluation blindness allows degradation to appear successful.

The system can remain coherent throughout the process.

That is why the absence of visible failure is not proof that meaning has been preserved.
